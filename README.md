# Laço de Luz · Estação Natal Jaguariúna 2026

Protótipo jogável (HTML/CSS/JS) da Secretaria Municipal de Cultura de Jaguariúna. Feito para celular em pé (retrato).

Abra este site no navegador do celular, de preferência em tela cheia e com o som ligado no primeiro toque.

- Desenhe um laço em volta das luzes para acender a cidade.
- Há um modo tranquilo, sem cronômetro.
- No fim, dá para baixar um card 9:16 e ver a programação (19/11 a 23/12).

Este repositório é só o protótipo para teste. Não coleta dados.
